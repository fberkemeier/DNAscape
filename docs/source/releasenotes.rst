Release Notes
=============

1.0.0
-----

DNAscape 1.0.0 includes the Python package, NiceGUI app, data conversion,
mapping, simulation, plotting, notebooks, and Sphinx documentation.

Docs in this revision:

* package and app workflows;
* data, ``rmap``, and ``rsim`` guides;
* notebook and API references;
* troubleshooting;
* placeholder figures for future screenshots and notebook plots.
