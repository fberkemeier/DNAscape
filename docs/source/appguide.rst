App guide
=========


Use the left-hand menu to move between workflows. Start with
:doc:`niceguiapp` for plots, files, navigation, region transforms and Settings.
Then open the guide for the page you are using.

* :doc:`datamanagement` prepares experimental or model-derived profiles.
* :doc:`mappingfunctions` infers a target from compatible inputs or predicts
  replication features from a model.
* :doc:`simulationengine` samples individual S phases and ensemble statistics.
* :doc:`analysis` compares prepared profiles and datasets.

For a first run with specific settings, follow :doc:`quickstart`.
